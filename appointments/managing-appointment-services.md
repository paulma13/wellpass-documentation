# How to manage appointment services

## Overview

Appointment services are the templates that define what you offer — for example, "60-Minute Private Reformer" or "Nutritional Consultation." You create and edit services from the **Appointments** page. Services can be made inactive to hide them from clients and staff without deleting them.

---

## Creating a new service

1. Go to **Appointments** in the left sidebar.
2. Click the **New Service** button (shown with a plus icon).
3. Fill in the service details (see field reference below).
4. Click **Save** (or the equivalent confirm button) to create the service.

---

## Editing an existing service

1. Go to **Appointments** in the left sidebar.
2. Find the service you want to edit and click on it.
3. Update the fields as needed.
4. Save your changes.

All fields are editable after creation.

---

## Deactivating a service

Services cannot be permanently deleted. Instead, use the **Active** toggle to control visibility.

- **Active on:** The service is visible and bookable by clients.
- **Active off:** The service is hidden from clients and will not appear as a booking option. Existing appointments for this service are not affected.

To deactivate a service, open it for editing and turn off the **Active** toggle, then save.

---

## Service fields reference

| Field | Description |
|---|---|
| **Branch** | The studio branch this service is offered at. |
| **Type** | An optional category for the service (e.g., Pilates, Yoga). Clearable. |
| **Name** | The display name clients and staff see. |
| **Description** | Optional details about the service shown to clients. |
| **Duration** | How long the session lasts. |
| **Price** | The default price for this service. Can be overridden when booking an individual appointment. |
| **Gender** | Optional gender restriction for who can book this service. |
| **Min Advance Booking** | How far in advance a client must book before the session time. |
| **Cancellation Window** | The cut-off period before the session within which cancellations are no longer allowed. |
| **Active** | Controls whether the service is visible and bookable by clients. |
| **Cover Image** | An image displayed for this service. Upload a file in 16:9 format. |
