# Viewing clients for a package

## Overview

Use this to see every client who holds or has ever held a specific package. This view is useful when you want to check who currently has active copies of a package, review pricing history, or audit any price changes your staff made when assigning it.

## How to open the client list for a package

1. Go to the **Packages** page in the left sidebar.
2. Click the **Packages** tab.
3. On the package row you want to inspect, click the **View client list** icon (the users icon on the right side of the row).
4. A modal opens titled with the package name and the total client count.

## What the table shows

Each row in the table is one client package — one instance of the template owned by one client.

- **Client** — the client's name and phone number.
- **Sessions** — the number of sessions remaining out of the total. For example, "7 / 10" means 7 sessions left from a 10-session package.
- **Expires** — the expiry date of the client's package. If the package has no expiry, this column is blank. Dates that have already passed are shown in red.
- **Status** — the current state of the client's package: **Active** (green), **Expired** (gray), or **Exhausted** (orange).
- **Payment** — how the client acquired the package. Shown as a badge: **via Wellpass** (blue, for purchases made through the Wellpass app), **Free** (violet), or **Cash** (gray).
- **Price Paid** — the amount recorded at the time of assignment or purchase.
- **Price Change Reason** — if your staff assigned this package at a price different from the standard price, the reason they entered is shown here. Use this column to review discount decisions and special pricing.

## Empty state

If no clients have been assigned or purchased this package yet, the modal shows: "No clients have purchased this package yet."
