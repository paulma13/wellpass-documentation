# Understanding the packages page

## Overview

The Packages page is where you manage everything related to session bundles in your studio. It has two tabs: **Packages** and **Client Packages**. The Packages tab shows the bundle templates you have created. The Client Packages tab shows every bundle currently or previously owned by a client across your entire studio.

Receptionists can view both tabs but cannot create, edit, activate, deactivate, or assign packages.

## The Packages tab

The Packages tab lists every package template you have created. Each row represents one template.

### Columns

- **Name** — the name of the package as it appears to clients and staff.
- **Description** — a short preview of the package description (truncated to 20 characters). Hover over the cell to read the full description.
- **Visibility** — whether the package is **Public** (visible in the Wellpass app for clients to purchase) or **Private** (only assignable by staff).
- **Valid for** — which services the package covers: Classes, Appointments, or both.
- **Sessions** — the number of sessions included in the package.
- **Active Clients** — how many clients currently hold an active copy of this package template.
- **Price** — the standard price of the package. Packages with no charge show as Free.
- **Validity** — how many days after purchase the package is valid. Packages with no expiry show as No expiry.
- **Status** — whether the package is currently **Active** or **Inactive**.

You can sort the table by any of these columns: Name, Sessions, Active Clients, Price, Validity, Status, and Visibility.

### Inactive packages

Inactive packages appear dimmed in the table. They cannot be assigned to new clients and, if they were public, they no longer appear in the Wellpass app. Clients who already own an inactive package are not affected — their sessions continue to work normally.

### Actions per row

Each row has two action icons on the right:

- **Assign to client** — opens the assignment flow to give this package to a client. This icon is disabled when the package is inactive.
- **View client list** — opens a modal showing all clients who hold or have held this package.

Each row also has a **status toggle switch** to activate or deactivate the package. This toggle is not visible to receptionists.

### Clicking a row

Clicking anywhere on a package row (other than the action icons) opens the edit modal for that package. This is not available to receptionists.

### Empty state

If you have no package templates yet, the page shows: "Create your first package to start selling session bundles to clients." Use the **New Package** button in the top right to create your first one. This button is not visible to receptionists.

## The Client Packages tab

The Client Packages tab shows a filterable list of every package owned by clients across your studio. Each row is one client package — meaning one instance of a template owned by one client.

Use this tab to monitor package usage, check client statuses, and track payment records across all clients at once. For a full explanation of how to use the filters and what each status means, see [Viewing all client packages](viewing-all-client-packages.md).
