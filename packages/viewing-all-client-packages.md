# Viewing all client packages

## Overview

The **Client Packages** tab on the Packages page gives you a studio-wide view of every package owned by any client. Use it to check on individual clients, monitor package usage across your studio, or find records with a specific status or payment method.

## How to access it

1. Go to the **Packages** page in the left sidebar.
2. Click the **Client Packages** tab.

The table loads all client packages across your studio, most recent first.

## Filtering the list

Four filters are available at the top of the table. You can use any combination of them at the same time.

- **Search** — type a client's name or phone number to find their packages.
- **Package** — filter by a specific package template to see only clients who own that bundle.
- **Status** — filter by the current state of the client package. See the status descriptions below.
- **Payment method** — filter by how the package was acquired: Cash, Card, or Free.

## Columns

- **Client** — the client's name and phone number.
- **Package** — the name of the package template this client owns.
- **Sessions** — remaining sessions out of the total. For example, "3 / 10" means 3 sessions left from a 10-session package.
- **Status** — the current state of the client package. See descriptions below.
- **Payment** — the payment method used. Shown as a badge: **Cash**, **Card** (with the amount shown), or **Free**.
- **Acquired** — the date the package was assigned or purchased.
- **Expires** — the expiry date of the package. Dates that have already passed are shown in red.

## Package statuses

- **Active** — the client has sessions remaining and the package has not expired. The package is currently usable.
- **Exhausted** — all sessions in the package have been used up. No sessions remain, so the package can no longer be used for bookings.
- **Expired** — the validity period passed before the client used all their sessions. The package can no longer be used even if sessions remain.
- **Awaiting Payment** — the client initiated a purchase through the Wellpass app but payment has not yet been confirmed. The package is not yet usable.
- **Payment Failed** — the client attempted to purchase the package through the Wellpass app but the card payment did not go through. No sessions were issued.

## Payment methods

- **Cash** — the package was assigned by a staff member and the client paid in person.
- **Card** — the client purchased the package through the Wellpass app using a card.
- **Free** — the package was assigned by a staff member at no charge.

## Clicking a row

Clicking any row in the Client Packages table opens the full profile for that client.
