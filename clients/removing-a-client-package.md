# Removing a package from a client

## Overview

Use this to cancel an active package that was assigned to a client in error, or when a refund or cancellation needs to be recorded. Removing a package immediately zeroes out the remaining sessions. This action cannot be undone.

## How to remove a package

1. Go to the **Clients** page in the left sidebar.
2. Find the client and click their row to open their profile.
3. Click the **Packages** tab.
4. Find the active package you want to remove. Only active packages show a trash icon.
5. Click the **trash icon** on the package card.
6. A confirmation modal appears with a warning that this action is irreversible.
7. Review the **Money was refunded** toggle:
   - Turn it **on** if you refunded the client's payment. The price paid for this package will be zeroed out in your reports, so it no longer appears as revenue.
   - Leave it **off** if no refund was given. The original payment amount stays in your reports.
8. Click **Confirm** to remove the package, or click **Cancel** to close the modal without making any changes.

## What happens when a package is removed

- The client's remaining sessions are set to zero immediately.
- Sessions that were already used are not reversed — past bookings that used this package keep their recorded payment of zero.
- The package status changes and it no longer appears as active.
- If you turned on the refund toggle, the price paid for the package is set to zero in your revenue reports.

## Which packages can be removed

Only **active** packages show the trash icon and can be removed. Expired packages (past their end date) and exhausted packages (all sessions used) do not show the trash icon and cannot be removed.

## Edge cases

- Removing a package does not change any past class or appointment bookings that used sessions from that package. Those bookings remain recorded with a price of zero.
- If you remove a package by mistake, you will need to assign a new package to restore the client's sessions. There is no undo.
