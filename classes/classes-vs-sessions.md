# Classes and sessions — what's the difference

## What a class is

A **class** is a template — the blueprint for a type of group activity you offer at your studio. It holds all the default information: the name, type (such as Pilates Reformer or Aerial Yoga), description, cover image, duration, maximum capacity, price, gender restriction, and the cancellation window.

Think of it like a recipe. A class called "Monday Morning Reformer" defines what the activity is, how long it lasts, and what it normally costs. The class itself has no date or time — it does not appear on your calendar. It just sits in your class library, ready to be scheduled.

Classes are managed from the **Classes** page.

## What a session is

A **session** is a specific occurrence of a class — one scheduled event on a particular date, at a particular time, at a particular branch, with assigned instructors.

Using the recipe analogy: if the class is the recipe, a session is the actual meal you cook from it on a specific evening. You might run the same class every Tuesday at 9 am, and each of those Tuesdays is its own session with its own roster of booked clients.

Sessions are created from the **Bulk Session Wizard** and appear on your **Calendar**. Each session can override the class defaults for price, capacity, and gender restriction. If a session has no price set, it uses the class default.

Key things you can do at the session level:
- Edit time, capacity, price, gender, and instructors for one session or many at once
- View and manage bookings and the waitlist
- Cancel a single session without affecting the class template or any other sessions

## Why it works this way

Separating the template from the schedule gives you flexibility without repetition.

You define the activity once — its name, what type it is, its default settings — and then generate as many scheduled instances as you need. Want to run the same class three times a week for three months? Create the class once, then use the Bulk Session Wizard to generate all the sessions across that date range in one step.

It also means you can adjust individual sessions when needed — change the capacity for a holiday slot, raise the price for a guest instructor session, or cancel a single date — without touching the class template or any other sessions on the calendar.
